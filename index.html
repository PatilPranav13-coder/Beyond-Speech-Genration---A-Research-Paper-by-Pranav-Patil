A framework for managing, pausing and resuming multiple interleaved conversational threads while preserving reasoning continuity.

01 / The research problem

Conversation is not a single queue.

Human conversations naturally contain temporary detours. A person can pause a complex explanation to ask a quick question, receive an answer, add a constraint or correction, and return to the larger discussion without reconstructing it from the beginning.

Conversational AI can preserve the transcript yet still lose the unfinished structure of an answer: what has already been delivered, what remains unresolved, and how a side exchange should change the next response.

Central research question

Can an AI system maintain multiple active conversational threads and resume an interrupted complex discussion from the correct reasoning point after handling temporary side questions?

02 / Proposed framework

Thread-Aware Conversational Architecture (TACA)

TACA is a proposed orchestration layer around a conversational language model and, in a later implementation, a streaming speech interface.

01 · Streaming interruption gate

Detects user input during generation and safely pauses or stops output.

02 · Intent and thread classifier

Distinguishes clarifications, side questions, added context, corrections and permanent topic changes.

03 · Thread graph and state store

Maintains parent and side threads, their relationships and lifecycle states.

04 · Answer checkpoint manager

Tracks delivered answer units, unresolved obligations, assumptions and the next planned response unit.

05 · Relevance-aware resumption

Decides whether to resume and incorporates side-thread information only when it genuinely affects the parent task.

06 · Interruptible response generation

Continues from the next unresolved unit rather than restarting the original answer.
